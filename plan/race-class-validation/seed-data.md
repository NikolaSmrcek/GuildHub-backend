> Items are drawn from all 6 Voidspire bosses. For armor types with fewer items in the seed catalog, items may be reused across characters (different characters can have report items for the same item — dpsImprovement values differ).

### dpsImprovement Values (example range)

To produce varied recommendation scores, dpsImprovement values span a range:

| Tier | dpsImprovement | Frequency |
|------|---------------|-----------|
| Large upgrade | 400–500 | ~25% of report items |
| Medium upgrade | 200–399 | ~50% of report items |
| Small upgrade | 50–199 | ~25% of report items |

### No Armor Mismatches

The armor validation in `RaidbotsService.createReport()` ensures all seeded report items pass the class-armor check:
- Cloth characters → only Cloth subclass items
- Leather characters → only Leather subclass items
- Mail characters → only Mail subclass items
- Plate characters → only Plate subclass items

Weapon items (Sword, Dagger, etc.) pass through without restriction since `validateClassArmor()` skips non-armor subclasses.
